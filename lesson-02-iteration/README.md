# Урок 2. Перебор элементов

## Итерируемые объекты

Перебрать можно только **итерируемые объекты**: строку (`str`), список (`list`), кортеж (`tuple`), множество (`set`), словарь (`dict`), диапазон (`range`).

Число — **не является** итерируемым, его нельзя напрямую перебрать.  
Преобразуйте его в строку (`str`).  
Не забудьте вернуть элементы обратно в число (`int`), если необходимо проводить с этими цифрами математические операции.

## Перебор элементов

Перебор элементов возможен с помощью:
- **генераторных выражений** (List Comprehension) — рекомендовано;
- **`for`** — длинно и не рекомендовано, но допустимо в задачах ЕГЭ;
- **функций `map()` и `filter()`** (применение функции ко всем элементам без явного цикла) — используется `map()`;
- **`while`** (перебор по индексам: `while i < len(s): print(s[i]); i += 1`) — не используется в задачах ЕГЭ.

## Генераторные выражения (List Comprehension)

Хорошей практикой является использование генеративных выражений вместо `for`. Это позволяет записать перебор, фильтрацию и действие в одну строку.

Синтаксис: `[действие for элемент in последовательность if условие]`

**Пример:**

    numbers = [1, 2, 3, 4, 5, 6]

    # Полный код через for
    squares = []
    for x in numbers:
        if x % 2 == 0:
            squares.append(x * x)

    # Сокращенный код (генератор)
    squares = [x * x for x in numbers if x % 2 == 0]

## Перебор пар, троек

Перебор пар, троек (задача #17) лучше через `zip`. Это безопаснее (нет выхода за границы) и короче:

    for a, b in zip(s, s[1:]):
        if a == b:
            print('Пара:', a, b)

## Перебор по индексу

Иногда нужно обратиться не к самому элементу, а к его позиции. Для этого используют перебор по индексу (`i`) через `range(len(...))`:

    s = 'Hello'
    for i in range(len(s)):
        print(i, s[i])

**Когда использовать:**
- Если нужно **изменить** элемент в списке на месте (в Python цикл `for x in s` создает копию, а `s[i] = ...` меняет оригинал).
- В задачах на два указателя (например, задание 24), где мы двигаем левый (`L`) и правый (`R`) указатели по индексам.

## Примеры

**Сумма цифр числа:**

    n = 12345
    total = sum(int(el) for el in str(n)) # 15

**Сумма чётных чисел в списке:**

    numbers = [1, 2, 3, 4, 5, 6]
    total = sum(x for x in numbers if x % 2 == 0) # 12

**Количество чётных чисел (два способа):**

    # Вариант 1 (быстрый, без выделения памяти)
    count = sum(1 for x in numbers if x % 2 == 0) # 3

    # Вариант 2 (через len, медленнее на больших данных)
    count = len([x for x in numbers if x % 2 == 0]) # 3

**Сумма цифр двоичного числа (два способа):**

    nb = '10101111'
    total = sum(int(el) for el in nb) # 6
    
    # Изящный вариант (количество единиц):
    count_ones = nb.count('1') # 6 

**Перебор всех троек списка:**

    nums = [1, 2, 3, 4, 5]
    for a, b, c in zip(nums, nums[1:], nums[2:]):
        print(a, b, c)
