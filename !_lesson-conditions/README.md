# Условия

## Базовый синтаксис

В Python условие пишется без скобок, но с двоеточием в конце строки. Блок кода выделяется отступом (4 пробела).  
Первое условие - `if`.  
Второе и последующие - `elif` (else if).  
Последнее - `else`.  

    x = 10
    if x > 0:
        print('Положительное')
    elif x == 0:
        print('Ноль')
    else:
        print('Отрицательное')

## Логические операторы

Для объединения условий используются `and`, `or`, `not`.

**Приоритет выполнения** (от высшего к низшему):
1. `not` (НЕ)
2. `and` (И)
3. `or` (ИЛИ)

*Лучше использовать скобки `()`, чтобы избежать ошибок и сделать код понятнее.*

    # Без скобок (сработает верно, но читается хуже)
    if x > 0 and x < 10 or x == 20:
    
    # Со скобками (наглядно)
    if (x > 0 and x < 10) or (x == 20):

## Тернарный оператор

Простые выражения можно записать в одну строку


    x = 10
    print('Чётное' if x % 2 == 0 else 'Нечётное')

## Использование if all() и if any()


`all()` — истина, если **все** элементы истинны (аналог логического **И**).  
`any()` — истина, если **хотя бы один** элемент истинен (аналог логического **ИЛИ** ).


    numbers = [2, 4, 6, 8]
    
    # Если все чётные, то...
    if all(x % 2 == 0 for x in numbers):
        print('Все чётные')

    # Если хотя бы один нечётный, то...
    if any(x % 2 != 0 for x in numbers):
        print('Есть нечётное')

    # Если все элементы различны (каждые элемент встречается роано один раз), то...
    if all(numbers.count(el) == 1 for el in numbers):
        print('Все элементы различны')

## Проверка вхождения (in)

Позволяет проверить, есть ли элемент в списке, строке или словаре.

    s = 'Hello'
    if 'e' in s:
        print('Буква e есть в строке')

## Сравнение цепочек

В Python можно писать двойные неравенства, как в математике.

    x = 15
    if 10 < x < 20:
        print('x от 10 до 20')

## Сложение булевых значений при проверке условия

В Python `True` — это `1`, а `False` — это `0`.  
Поэтому для проверки количества выполненных условий можно сложить булевые значения этих проверок.

    a, b, c = 2, 4, 7
    count = (a % 2 == 0) + (b % 2 == 0) + (c % 2 == 0)
    print(count)  # 2
