# Комбинаторика

Задание #08 КИМ ЕГЭ в 2027 году.

## Основы

По условиям задач #8 КИМ ЕГЭ необходимо сформировать все комбинации букв (список слов) либо цифр (список чисел).  
Требуется найти первое, последнее слово. число либо количество слов, чисел, удовлетворяющих условиям задачи в отсортированном, пронумерованном списке.

Для перебора всех возможных комбинаций используется функция `product` из модуля `itertools`.  
Количество букв в слове - аргумент `repeat=`.   
Сортировка в алфавитном порядке - функция `sorted()`.  
"Собрать" в слово - метод `.join()`.

    from itertools import product

    for word in product(sorted('АБВ'), repeat=2):
        print(''.join(word)) #  АА, АБ, АВ, БА, ББ, БВ, ВА, ВБ, ВВ

## Нумерация

Для нумерации используем переменную, например, `n`, инициализируем **до** цикла `for`, увеличиваем на `1` **сразу после цикла**, т.е., считаем **все** строки, слова, числа.  
Либо используем `enumerate` (начните нумерацию с `1`).

    from itertools import product

    n = 0
    for word in product('АБВ', repeat=3):
        n += 1
        s = ''.join(word) # Сохраняем слово в переменную
        if s == 'БАВ':
            print(n, s)
            break

Либо используем `enumerate` (нумерация начинается с 1).    

    from itertools import product

    for index, word in enumerate(product('АБВ', repeat=3), start=1):
        if ''.join(word) == 'БАВ':
            print(index)
            break


## Подсчет количества слов, чисел, строк, удовлетворяющих условиям

Если нужно просто посчитать, сколько слов удовлетворяют условию, используем счетчик `k` - инициализируем **до** цикла `for`, увеличиваем на единицу **после** проверки всех условий.

    from itertools import product

    k = 0
    for word in product('АБВ', repeat=3):
        s = ''.join(word)
        if s[0] == 'А': # пример условия
            k += 1
    print(k)

## Особенности работы с числами
Числа могут обрабатываться **как слова**, число - слово, цифра - буква;  
Однако нужно учитывать, что в данном случае 'число' - это строка;  
Числа могут обрабатываться **числами** - используйте `for number in (product(range(10), repeat=3)`;  
**Важно**: число не может **начинаться с нуля**, поэтому обязательно проверьте `word[0] != '0'` либо `number[0] != 0`.

## Условия
В задачах используются типовые условия, в том числе:  
'слова с чётным номером' - `n % 2 == 0`;  
'начинается c букв А и О' - `word[0] in 'АО'`;  
'не начинается c букв А и О' - `word[0] not in 'АО'`;  
'содержит ровно две буквы А' - `word.count('А') == 2`;  
'не содержит букв А' - `'А' not in word`;  
'содержит две буквы А, но не стоящие рядом' - `word.count('А') == 2 and 'АА' not in word` (использовать `.join()` - в данном случае - обязательно);  
'чётные и нечётные не стоят рядом' - `number[0]%2 != number[1]%2 != number[2]%2 != ...`;  
'числа не повторяются' - `if len(set(s)) ==` (множество не содержит повторов элементов) и другие.
