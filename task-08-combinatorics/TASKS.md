## Задача 1
**Условие:** Все пятибуквенные слова, составленные из букв С, Т, Р, Е, Л, А, записаны в алфавитном порядке и пронумерованы.  
Начало списка: 1. AAAAA, 2. AAAAE, 3. ААААЛ...  
Определите, под каким номером в этом списке стоит последнее слово с нечётным номером, которое не начинается с букв А, С и Т и при этом содержит в своей записи ровно две буквы Е, не идущие подряд.  
**Решение:**

    from itertools import product

    for n, w in enumerate(product(sorted('СТРЕЛА'), repeat=5), 1):
        word = ''.join(w)
        if n % 2 != 0 and word[0] not in 'АСТ' and word.count('Е') == 2 and 'ЕЕ' not in word:
            print(n, word) # Последняя строка в выводе и есть ответ: 4295 РЕТЕС


## Задача 2
**Условие:** Сколько существует чётных четырехзначных чисел, составленных из цифр 1, 2, 3, 4, 5?  
**Решение:**

    from itertools import product
    k = 0
    for word in product('12345', repeat=4):
        if ''.join(word)[-1] in '24':
            k += 1
    print(k) # 250


## Задача 3
**Условие:** Сколько существует шестизначных чисел, в которых никакая цифра не повторяется дважды, а цифры 1 и 3 не стоят рядом друг с другом?  
**Решение:**

    from itertools import product

    count = 0
    for word in product('0123456789', repeat=6):
        s = ''.join(word)
        if s[0] != '0' and len(set(s)) == 6 and '13' not in s and '31' not in s:
            count += 1

    print(count) # 120960


## Задача 4
**Условие:** Все пятибуквенные слова, составленные из букв Ц, И, Т, Р, У, С, записаны в алфавитном порядке и пронумерованы.  
Начало списка: 1. ИИИИИ, 2. ИИИИР, 3. ИИИИС...  
Под каким номером в списке идёт последнее слово, которое содержит ровно две буквы И и не содержит букв Ц, стоящих рядом?  
**Решение:**

    from itertools import product

    for n, w in enumerate(product(sorted('ЦИТРУС'), repeat=5), 1):
        word = ''.join(w)
        if word.count('И') == 2 and 'ЦЦ' not in word:
            print(n, word) # Последняя строка в выводе и есть ответ: 7525 ЦИИИЦ
