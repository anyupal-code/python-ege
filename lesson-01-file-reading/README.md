# Чтение из файла

## Цель

Научиться читать данные из файла коротким и понятным кодом.  
Чтение файла из текстового файла задачи — в заданиях 9, 17, 24, 26 и 27.  
*В задании 9 необходимо ручное копирование данных из файла электронной таблицы в текстовый файл.*

## 1. Одно число в строке

Если в каждой строке файла ОДНО число, файл можно прочитать ОДНОЙ строчкой кода (например, задание 17):

```python
s = list(map(int, open('one.txt')))
# или
s = [int(el) for el in open('one.txt')]

# для вещественных (float)
s = list(map(float, open('one.txt')))
```

## 2. Несколько чисел в строке

Если в каждой строке файла НЕСКОЛЬКО чисел, файл можно прочитать ДВУМЯ строчками кода (например, задание 9):

```python
for st in open('many.txt'):
    s = list(map(int, st.split()))

# если в строках одинаковое количество чисел (например, три) - их можно получить сразу в переменные:
for st in open('many.txt'):
    a, b, c = map(int, st.split())
```

## 3. Непрерывная строка

Если файл — непрерывная строка символов, файл читается одной строчкой (например, задание 24):

```python
s = open('continuous.txt').readline()
```

## Важное замечание

В этом курсе мы часто не закрываем файлы вручную (не используем `with open`), потому что на ЕГЭ это не критично и экономит время.  
Однако в реальной работе (в промышленном программировании) правильнее использовать:

```python
with open('one.txt') as f:
    pass # вместо pass - код работы с файлом
```

Это гарантирует, что файл закроется даже при ошибке.
