# Таблицы истинности

Задание #02 КИМ ЕГЭ в 2027 году.

## Основы

Необходимо восстановить таблицу истинности для логического выражения.
Переменные `x`, `y`, `z`, `w` принимают значения `0` (ложь) или `1` (истина).

## Решение
Перебор всех комбинаций возможен вложенными циклами:

```python
for x in 0,2:
    for y in 0,2:
        for z in 0,2:
            for w in 0,2:
                print(x, y, z, w)
```
Либо используйте функцию `product` из модуля `itertools`.
Количество переменных в наборе — аргумент `repeat=`.

```python
from itertools import product

for x, y, z, w in product([0, 1], repeat=4):
    print(x, y, z, w)
```

В условиях задач логические выражения записываются математическими символами.  
В Python их нужно заменить на соответствующие логические операторы:

| Математический символ | Значение | Оператор Python |
| :--- | :--- | :--- |
| `¬A` | НЕ (инверсия) | `not A` |
| `A ∧ B` | И (конъюнкция) | `A and B` |
| `A ∨ B` | ИЛИ (дизъюнкция) | `A or B` |
| `A → B` | Импликация (следование) | `not A or B`|
| `A ≡ B` | Эквивалентность (равенство) | `A == B` |
| `A ⊕ B` | Исключающее ИЛИ (XOR) | `A != B` |

**Логические операции выполняются в определённой порядке (приоритет в Python):**  
1. Скобки `()` имеют наивысший приоритет и позволяют переопределить порядок действий (иногда необходимо использовать дополнительные скобки для определения порядка выполнения действий).  
2. Далее выполняется `not` (инверсия).  
2. Затем `and` (конъюнкция).  
3. Потом `or` (дизъюнкция).  
4. Операторы сравнения (`==`, `!=`, `<=`) имеют более низкий приоритет, чем логические `and` и `or`.  

Импликация `A → B` при записи через `not A or B` из-за приоритета `not` и `or` может потребовать дополнительных скобок: `(not A) or B`.  

В Python `A → B` почти всегда можно записать как `A <= B`, так как импликация ложна только когда A=1, B=0, что совпадает с оператором `<=` для булевых значений.  
Однако, правильнее использовать `not A or B`.  

**Пример:** выражение `((x ≡ ¬y) → ¬(z → x)) ∨ ¬w` на Python записывается так: `((x == (not y)) <= (not (z <= x))) or (not w)`  
Или в более читаемом виде: `(not (x == (not y)) or (not (not z or x))) or (not w)`

# Более сложный вариант решения

Этот вариант более сложен по коду, но не требует последующего анализа полученной таблицы и сразу даёт однозначный ответ.  
Почти всегда быстрее воспользоваться простым перебором вариантов строк (см. выше).  
Однако приведём и этот вариант решения задачи:  

**Условие** Миша заполнял таблицу истинности логической функции `F = x → ¬((y → z) ∧ (z ≡ ¬w))`.  
Но успел заполнить лишь фрагмент из трёх различных её строк, даже не указав, какому столбцу таблицы соответствует каждая из переменных w, x, y, z: 

    -   -   -   -   F  
    0   -   -   0   0  
    -   1   1   -   0  
    -   1   0   0   0  

Определите, какому столбцу таблицы соответствует каждая из переменных w, x, y, z.  
В ответе напишите буквы w, x, y, z в том порядке, в котором идут соответствующие им столбцы

**Решение**
```python
from itertools import *

def f(x, y, w, z):
    return (x <= (not((y <= z) and (z == (not w)))))
for a1, a2, a3, a4, a5 in product([0, 1], repeat=5):
    st = [(0, a1, a2, 0), (a3, 1, 1, a4), (a5, 1, 0, 0)]
    if len(set(st)) == 3:
        for comb in permutations('xywz'):
            if [f(**dict(zip(comb, r))) for r in st] == [0, 0, 0]:
                print((''.join(comb))) # wxzy
```
В строке `st = [(0, a1, a2, 0), (a3, 1, 1, a4), (a5, 1, 0, 0)]` - значения из строк таблицы и переменные (где прочерк).  
Функция `permutations('xywz')`генерирует **уникальные** комбинации переменных.  
Строка `if [f(**dict(zip(comb, r))) for r in st] == [0, 0, 0]:` выбирает только комбинации соответствующие значению функции (последний столбец таблицы задачи).
