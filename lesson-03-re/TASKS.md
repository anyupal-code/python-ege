## Задача 1

**Условие:**  
Текстовый файл состоит из цифр `0, 6, 7, 8, 9` и знаков `–` и `*`.  
Определите максимальное количество символов в непрерывной последовательности, которая является корректным арифметическим выражением с целыми неотрицательными числами.  
Два знака операций не стоят рядом, ведущих нулей нет, число `0` не имеет знака.

**Решение:**

```python
# Тестовый файл task_1.txt лежат рядом с этим скриптом.
from re import findall

s = open("task_1.txt").readline()
num = r"(?:[6789][06789]*|0)"
reg = rf"{num}(?:[-*]{num})+" 
matches = findall(reg, s)
print(max(len(el) for el in matches))# 154
```

**Разбор:**

- `num = r"([6789][06789]*|0)"` — «правильное» число: либо начинается с `6–9` и продолжается любыми цифрами из `0, 6–9`, либо это просто `0`.
- `reg = rf"{num}(?:[-*]{num})+"` — выражение: число, затем один или более фрагментов «операция + число».
- `findall` возвращает список объекты совпадений, `(max(len(el) for el in matches))` выбирает самое длинное.

## Задача 2

**Условие:**  
Текстовый файл состоит из десятичных цифр и заглавных букв латинского алфавита.  
Определите в этом файле последовательность идущих подряд символов, представляющих собой запись максимального чётного 14-ричного числа.  
В ответе запишите количество символов (значащих цифр в записи числа) в этой последовательности. 
Примечание. Латинские буквы A, B, C и D означают цифры из алфавита 14-ричной системы счисления.  

**Решение:**
```python
# Тестовый файл task_2.txt лежат рядом с этим скриптом.
from re import findall

s = open("task_2.txt").readline().strip()
matches = findall(r'(?:[0-9A-D]*[02468AC])', s)
print(max(len(m) for m in matches))  # 2598
# Сознательно не проверяем 0, 2, 4, ... - нужно максимальное число
```
