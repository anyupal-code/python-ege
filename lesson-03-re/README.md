# Регулярные выражения

Используются, в том числе, в задании #24 КИМ ЕГЭ в 2027 году.

---

## Основное

Задачи типа 24 построены на обработке длинной строки из файла.  
Нужно найти максимальную длину подстроки, которая удовлетворяет некоторому правилу (или посчитать количество вхождений).  
В подобных задачах удобно использовать модуль стандартную библиотеку`re`.   
Необходимо **описать шаблон**, найти все фрагменты строки, которые ему соответствуют, выбрать самый длинный либо посчитать количество таких подстрок.

**Синтаксис:**

Открытие файла - чтение строкой `open("").readline()`.  
Шаблон поиска - r-строка `r''`  
Функция `matches = findall(r'...', s)` возвращает список всех неперекрывающихся совпадений с шаблоном.  
Самая длинная строка из списка - `max(len(el) for el in matches)`, альтернативный вариант - максимум по длине `len(max(matches, key=len))`.  
**Важно:** `+` и `*` в регулярках «жадные» — они захватывают максимум возможного. Если нужен минимальный захват, ставят `?` после квантификатора (`+?`).  

```python
from re import *
s = open("24.txt").readline()
matches = findall(r'шаблон', s)
print(max(len(el) for el in matches))
```
---

## Шаблоны RE-строки

### Классы символов

| Шаблон | Значение |
|---|---|
| `(?:...)` | незахватывающая группа |
| `[ABC]` | один символ из A, B, C |
| `[^ABC]` | один символ, **кроме** A, B, C |
| `[A-Z]` | одна заглавная латинская буква |
| `[0-9]` | одна цифра |
| `(.)` | любой символ (кроме перевода строки) **в группе**, иначе - просто символ `.` |
| `\d` | цифра (шире, чем `[0-9]`) - редко |
| `\w` | буква/цифра/подчёркивание - очень редко|



### Квантификаторы

| Шаблон | Значение |
|---|---|
| `*` | 0 или больше |
| `+` | 1 или больше |
| `?` | 0 или 1 |
| `{n}` | ровно n |
| `{n,m}` | от n до m |
| `\1` | обратная ссылка на группу №1 |


### Жадность

`A+` захватит **максимально возможную** цепочку из A. Если нужно наоборот — `A+?`.

## Решение задач
### Найти максимальную длину подстроки

**Условие:** Текстовый файл состоит из заглавных латинских букв. Найдите максимальную длину подстроки, состоящей только из букв `A`, `B` и `C`.

**Решение:**

```python
from re import *
s = open("24.txt").readline()
matches = findall(r'[ABC]+', s)
print(max(len(el) for el in matches))
```

`[ABC]+` означает «один или более символов из набора A, B, C подряд». `findall` собирает все такие цепочки, `max` максимальный по длине.

---

### Найти длину самой длинной цепочки одинаковых символов

**Условие:** В строке из заглавных латинских букв найдите максимальную длину цепочки из одинаковых подряд идущих символов.

**Решение:**

```python
from re import *
s = open("24.txt").readline()
matches = findall(r'(.)\1*', s)
print(max(len(el) for el in matches))
```

`(.)` — любой символ (захватывающая группа). `\1*` — ноль или более повторов **того же самого** символа. Вместе: «символ и все его повторы подряд».

**Альтернатива без регулярных выражений**:

```python
s = open("24.txt").readline().strip()
mx = cur = 1
for i in range(1, len(s)):
    if s[i] == s[i-1]:
        cur += 1
    else:
        cur = 1
    mx = max(mx, cur)
print(mx)
```

### Повторяющийся блок

**Условие:** Найдите максимальную длину цепочки, состоящей из повторяющегося фрагмента `XYZ` (последний фрагмент может быть неполным).

**Решение:**

```python
from re import *
s = open("24.txt").readline()
matches = findall(r'(?:XYZ)+(?:X|XY)?', s)
print(len(max(matches, key=len)))
```

- `(?:XYZ)+` — один или более полных блоков `XYZ`. `(?:...)` — незахватывающая группа (нужна, чтобы `+` применялся ко всему блоку, а не к последней букве).
- `(?:X|XY)?` — необязательный «хвост»: один `X` или `XY`.

## Функция `finditer` (когда нужны позиции или группы)

Если `findall` возвращает только текст, то `finditer` даёт объекты с методами `.group()`, `.start()`, `.end()`:

```python
from re import *
s = open("24.txt").readline()
best = max(finditer(r'[ABC]+', s), key=lambda m: len(m.group()))
print(len(best.group()))
```

Это удобно, если потом нужно проверить, что было **внутри** совпадения (например, через `m.group(1)` для захватывающей группы).
