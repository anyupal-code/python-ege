# IP-адреса и маски
Задание #13 КИМ ЕГЭ в 2027 году.

## Основы
Библиотека `ipaddress` создаёт сеть по адресу сети/адресу узла сети и маске.
Полученный объект `net` содержит, в том числе:

- сеть/маску в формате количества единиц `192.168.0.0/24` (24 единицы в маске);
- все IP-адреса сети (можно получить, например, через `for ip in net:`);
- `net.netmask` — маска сети (например, `255.255.255.0`);
- `net.network_address` — адрес сети (как объект, можно сравнить или перевести в строку);
- `net.hosts()` — итератор по всем адресам для устройств (без сети и broadcast).

```python
from ipaddress import *

# Создаем сеть. Второй параметр False (strict=False) разрешает передавать IP хоста
net = ip_network('10.100.202.34/255.255.240.0', False)
```

## Основные свойства объекта сети
Объект сети `net`, созданный `ip_network()`, ведёт себя как список всех IP-адресов:

- `net[0]` — адрес сети;
- `net[-1]` — широковещательный адрес (broadcast);
- `net[1]` — наименьший, который может быть назначен узлу;
- `net[-2]` — наибольший, который может быть назначен узлу;
- `net.num_addresses` — общее количество адресов в сети, включая адрес сети и широковещательный адрес (broadcast);
- `net.num_addresses - 2` — количество устройств (хостов).

```python
# Последний адрес для устройства
from ipaddress import *

net = ip_network('10.100.202.34/255.255.240.0', False)
print(net[-2])
```

## Перевод в двоичный вид и срезы
Объекты `ipaddress` напрямую переводятся в двоичную строку без точек:

```python
from ipaddress import *

ip = ip_address('192.168.1.10')
ip_b = f'{ip:b}'  # '11000000101010000000000100001010' (32 бита)
```

С этой строкой можно работать через срезы:

- `ip_b[:16]` — два левых байта (первые 16 бит);
- `ip_b[16:]` — два правых байта (последние 16 бит).

## Нахождение IP-адреса
Перебрать адреса можно циклом `for` (если нужно проверить условие):

```python
from ipaddress import *

net = ip_network('10.100.202.34/255.255.240.0', False)
for ip in net:
    if ...:  # сюда вставляется нужное условие
        print(ip)
```

Либо найти нужный адрес срезом (если известен его индекс в сети):

```python
from ipaddress import *

net = ip_network('10.100.202.34/255.255.240.0', False)
print(net[15])   # 16-й адрес (сеть = net[0])
print(net[-2])   # предпоследний (последний для устройств)
```

Индексы в `net` начинаются с 0, как в списках.

## Нахождение маски
Если в задаче дан IP-адрес узла и адрес сети, а нужно найти маску, можно перебрать маски от 0 до 32.

```python
from ipaddress import *

for m in range(33):
    # Создаем сеть с текущей маской
    net = ip_network(f'192.168.1.133/{m}', False)
    
    # Сравниваем адрес сети как строку
    if str(net.network_address) == '192.168.1.128':
        print(net.netmask)
        break
```

Если в задачах дан IP-адрес узла и адрес сети, а нужно найти маску в формате `255.255.255.A`, можно перебрать возможные значения `A` в двоичном виде.
Маска заполняется 1 слева направо — так проще запомнить все валидные маски.
Затем `A` переводится в `int`. Лучше использовать `f''`.

```python
from ipaddress import *

# Маска `255.255.255.A`.
# Найти наименьшее `A`, при котором адрес сети равен `192.168.0.0`.
masks = [
    '00000000',
    '10000000',
    '11000000',
    '11100000',
    '11110000',
    '11111000',
    '11111100',
    '11111110',
    '11111111'
]

for A in masks:
    net = ip_network(f'192.168.0.15/255.255.255.{int(A, 2)}', False)
    
    # Проверяем адрес сети
    if str(net.network_address) == '192.168.0.0':
        print(f'Найдено A = {int(A, 2)} (маска: {net.netmask})')
        break
```
