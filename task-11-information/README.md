# Вычисление количества информации

Задание #11 КИМ ЕГЭ в 2027 году.

## Основы

Вычисление объёма информации при алфавитном подходе.  
Задачи на серийный номер `sn` или идентификатор`id`.  

Основные формулы:
- `N = 2^i` — связь мощности алфавита (N) и информационного веса одного символа (i). 
- `I = K * i` — объём сообщения (I), где `K` — количество символов, `i` — вес одного символа.
- Перевод единиц: `1 байт = 8 бит`, `1 Кбайт = 1024 байт`, `1 Мбайт = 1024 Кбайт`.
___

## Расчёт информационного объёма серийного номера, идентификатора в Python

Для перевода `N` (мощность алфавита) в `i` (объём одного символа) нужно найти логарифм по основанию 2 `log2(N)` с округлением вверх `ceil` из модуля `math` или функция `bit_length()`.

Для определения информационного объёма серийного номера `sn` необходимо умножить объём одного символа на количество символов - длину серийного номера.  
Для хранения одного `sn` используется минимальное **целое** количество байт - требуется повторное округление вверх `ceil` при переводе в байты.  
Таким образом объём одного серийного номера `sn` равен: 
```python
from math import *

al = 150  # мощность алфавита
dl = 60  # длина серийного номера
sn = ceil(ceil(log2(al)) * dl / 8)
print(sn)
```
___
## Решение задач
### A. Найти мощность алфавита
Если нужно найти **мощность алфавита** `al`, значит, длина `dl` - дана в задаче.  
Подбираем перебором мощность алфавита `al` в цикле `for`.  
Вычисляем информационный объём серийного номера по стандартной общей формуле `sn = ceil(ceil(log2(al)) * dl / 8)`.  
Проверяем условие задачи, выводим все результаты, выбираем нужный.  

```python
# Серийный номер, состоит из 143 символов.
# Известно, что для хранения 9800 серийных номеров отведено не более 780 Кбайт памяти.
# Определите максимально возможную мощность алфавита, используемого для записи серийных номеров.

from math import *
dl = 143 # по условию задачи
for al in range(1, 1000):
    sn = ceil(ceil(log2(al))*dl/8)/1024 # по условию - в Килобайтах
    if 9800*sn <= 780:
        print(al) # 16
```

### B. Найти длину серийного номера
Если нужно найти **длину** `dl`, значит, мощность алфавита `al` - дана в задаче.  
Подбираем перебором длину `dl` в цикле `for`.  
Вычисляем информационный объём серийного номера по стандартной общей формуле `sn = ceil(ceil(log2(al)) * dl / 8)`.  
Проверяем условие задачи, выводим все результаты, выбираем нужный.  

```python
# Серийный номер содержит десятичные цифры и символы из 120-символьного специального алфавита.
# Известно, что для хранения 12 755 226 серийных номеров отведено не более 5 Гбайт памяти. 
# Определите максимально допустимую длину серийного номера. 
from math import*
al = 130
for dl in range(1, 1001):
    sn = ceil(ceil(log2(al))*dl/8)/1024/1024/1024
    if sn*12755226 <= 5:
        print(dl) # 420
```

### C. Найти информационный объём количества серийных номеров
Если нужно найти информационный объём какого-то количества серийных номеров, значит, алфавит `al` и длина `dl` - даны в задаче.  
Вычисляем информационный объём серийного номера по стандартной общей формуле `sn = ceil(ceil(log2(al)) * dl / 8)`.  
Умножаем информационный объём одного серийного номера на нужное количество серийных номеров.  

```python
# Идентификатор состоит из 257 символов и содержит только цифры семнадцатеричной системы счисления и символы из 4080-символьного специального алфавита. 
# Определите объём памяти (в Мбайт), необходимый для хранения 8 388 608 идентификаторов.
from math import*
dl = 257
al = 4097
sn = ceil(ceil(log2(al))*dl/8)/1024/1024
print(sn*8388608) # 3344
```
___
## Стандартные функции модуля math

- `ceil()` — округление вверх до ближайшего целого. Используется для перевода бит в байты и для нахождения `i`.
- `log2` — логарифм по основанию 2 для перевода мощности алфавита в информационный объём одного символа.   
- `int.bit_length()` — возвращает количество бит, необходимых для представления числа в двоичной системе. Например, `(50).bit_length()` вернет `6`.
