## Перевод из десятичной системы счисления

Последовательно производится целочисленное деление исходного числа на новую систему счисления.  
Остаток от деления — это и есть цифра числа в новой системе счисления.  
Реализуется в цикле `while`.

```python
# считаем количество нулей в числе в системе счисления с основанием 8 непосредственно во время преобразования числа
n = 123456
c = 0
while n:
    if n % 8 == 0: c += 1
    n = n // 8
print(c)
```

Если в выражении есть переменная, мы перебираем её значения в заданном диапазоне и проверяем условие для каждого.

```python
# Найдём наибольшее x в диапазоне от 1 до 2400, при котором результат выражения 
# n = 7 * 9**210 + 6 * 9**110 - x, записанный в 9-ричной системе, содержит ровно 100 нулей
ans = None
for x in range(1, 2401):
    n = 7 * 9**210 + 6 * 9**110 - x
    c = 0
    while n:
        if n % 9 == 0: c += 1
        n = n // 9
    if c == 100: ans = x
print(ans)  # 2394
```

## Перевод в десятичную систему счисления

Дано число или арифметическое выражение, записанное в системе счисления с основанием 29, содержащее `x` — неизвестную цифру алфавита системы счисления.  
Для определения `x` лучше использовать функцию `printable` из встроенной библиотеки `string`.

```python
from string import *
print(printable[:29])
```

Либо сразу:

```python
from string import *
for x in printable[:29]:
    pass # заглушка, чтобы код был валидным
```

Для числа или арифметического выражения требуется перевод в `int`, так как любая система счисления, кроме десятичной, — **строка**.  
Используйте и `f''` для вставки переменной, и `int()` с указанием системы счисления.

```python
from string import *
for x in printable[:29]:
    # Подставляем x в строку и переводим в десятичную
    num = int(f'1{x}2', 29)
    if num % 3 == 0:  # пример условия
        print(x, num)
```

## Стандартные системы счисления

Для стандартных систем (2, 8, 16) в Python есть встроенные функции:

```python
n = 255
print(bin(n)[2:])  # 11111111 (без 0b)
print(oct(n)[2:])  # 377 (без 0o)
print(hex(n)[2:])  # ff (без 0x)
```

Использование `f''` делает код лаконичнее:

```python
n = 255
print(f'{n:b}')  # 11111111
print(f'{n:o}')  # 377
print(f'{n:x}')  # ff
```

Для перевода из строки в десятичную используйте `int()` с указанием исходной системы счисления:

```python
n = '123123123'
print(int(n, 4))
```
